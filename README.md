# Bangsaen OOH Dashboard

Feasibility dashboard comparing two OOH investment models in Bangsaen for Plan B Media.

## View

Live: https://zalalink-web.github.io/bangsaen-dashboard/

## Stack

Single-file standalone HTML — Chart.js, Leaflet (CartoDB tiles), vanilla JS. Optional live data via Google Apps Script endpoint.

## Local use

Open `index.html` in any modern browser. To pull live data, paste the Apps Script `/exec` URL into the input and click load.
